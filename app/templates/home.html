Modalità demo: che cosa contiene

I dati

  • Archivio documentale sintetico Idrometrica: {{ riepilogo_demo.n_file }} file raccolti in {{ riepilogo_demo.n_famiglie }} famiglie.
  • Listino commerciale: {{ riepilogo_demo.n_articoli }} articoli.
  • Anagrafica articoli, per l'arricchimento dei dati.

Dati interamente di fantasia, dichiarati tali: nessun riferimento a prodotti, clienti o fornitori reali.

Che cosa è già stato fatto

  • Inventario dell'archivio e riconoscimento delle famiglie dall'albero delle cartelle.
  • Listino importato e riconciliato: copertura delle famiglie al {{ riepilogo_demo.copertura_famiglie }}%.
  • Lingue, date e revisioni dei documenti derivate dai nomi file.
  • Vigenza calcolata: {{ riepilogo_demo.n_candidati }} {{ "documento candidato" if riepilogo_demo.n_candidati == 1 else "documenti candidati" }} ad aggiornamento.
  • Scansione dei contenuti eseguita: {{ riepilogo_demo.n_segnalazioni_scansione }} segnalazioni di riservatezza.

Dove guardare

  • Strutturare · Ricostruzione, per le misure di copertura.
  • Sorvegliare · Vigenza, per le segnalazioni aperte.
  • Consultare · Wiki delle famiglie, per le schede generate.

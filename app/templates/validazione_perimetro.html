Come funziona il ciclo agentico

Questa pagina è il punto di scambio tra Wikify e l'agente di rilevazione (Claude o Claude Code). Il principio di fondo: l'agente propone, l'umano dispone. Nessuna classificazione entra nel sistema senza una conferma umana, e l'agente consulta esclusivamente i file che il triage ha qualificato Condivisibili.

  1. Scarica il perimetro condivisibile: il file perimetro_condivisibile.json elenca i soli file che l'agente è autorizzato a leggere (qualifica Condivisibile nel triage della scansione scelta). I file Riservati o Da valutare restano fuori: è il cancello di sicurezza dell'intero ciclo.
  2. Scarica le istruzioni per l'agente: contengono la procedura vincolante (leggere solo il perimetro, citare sempre l'evidenza, dichiarare una confidenza onesta, sola lettura) e il formato di consegna wikify-bozza/1.0 con le tassonomie ammesse.
  3. Consegna all'agente perimetro, istruzioni e accesso in lettura alle cartelle: l'agente esamina i file ammessi e produce un file JSON di bozza per ogni cartella progetto (proposte di tipologia, riservatezza, versione ufficiale e forma delle caratteristiche, ognuna con citazione testuale a supporto).
  4. Importa le bozze qui sotto: la validazione severa scarta ogni proposta senza evidenza o fuori tassonomia; le proposte accettate entrano nella coda di revisione, ordinata con i casi più dubbi in cima.
  5. Valida e misura: le conferme e le correzioni del responsabile tecnico alimentano le metriche di affidabilità; l'export delle correzioni si restituisce all'agente come esempi per il lotto successivo.
